# Artwork

The four original project banners were created with the built-in image-generation tool for this portfolio template. They are illustrative artwork, not clinical data or screenshots from the named projects. The original supplied layout guided the subject matter and palette.

These unused banners were removed from `static/images/` during asset cleanup; the filenames and prompts below are historical records. Emergent Sandbox (formerly Emergent Garden and Emergence Playground), Nostalgia Desktop and Further Down, Still use Michael's supplied project screenshots. The thesis entries use his actual analysis figures. The current project images are documented in [project sources](project-sources.md).

## Generation prompts

### medical-image-ai

File: `static/images/medical-image-ai.png`

Use case: scientific-educational. Asset type: wide website portfolio project banner, 1536 by 512. Create a photorealistic decorative H&E histology micrograph of glandular tissue, packed pink and purple oval glands with pale lumens, tiny purple nuclei and flowing pink extracellular matrix. Natural scientific microscope texture, bright light pink background, rich violet nuclei, viewed directly from above. Fill the entire horizontal frame with tissue, no margins, labels, text, interface, logos or watermark. This is illustrative portfolio artwork, not clinical data.

### emergent-garden

File: `static/images/emergent-garden.png`

Use case: stylized-concept. Asset type: wide website portfolio project banner, 1536 by 512. Beautiful particle simulation on a nearly black navy background. Hundreds of tiny crisp luminous individual dots cluster organically into swirling ribbons and separate little living colonies: golden yellow and coral pink on left, violet and electric blue in middle, bright turquoise flowing up at center right, fuchsia at lower right. Particle-life simulation aesthetic, restrained glow, lots of near-black negative space between clusters, elegant scientific generative artwork, not outer space. Fill entire horizontal frame. No text, borders, logos, gradients filling the background or watermark.

### nostalgia-simulator

File: `static/images/nostalgia-simulator.png`

Use case: ui-mockup. Asset type: wide website portfolio project banner, 1536 by 512. A lovingly recreated pixel-crisp retro mid-1990s computer desktop, teal blue-green desktop background, cream gray beveled windows, deep navy blue title bars, pixel monospaced typography. Main compact window near center-right with exact title "Nostalgia Simulator" and exact text "A simpler time." inside next to a small CRT computer icon. Layer one partly obscured gray window behind on right. On left small desktop icons: beige computer labelled "My Computer", manila folder labelled "Documents", lined paper labelled "Notes.txt". No modern UI, no browser frame, no logo, no watermark. Wide panoramic composition closely packed, nostalgic authentic retro screenshot, clean readable small text.

### further-down-still

File: `static/images/further-down-still.png`

Use case: stylized-concept. Asset type: wide website portfolio project banner, 1536 by 512. Gorgeous atmospheric 2D side-scrolling pixel-art action game screenshot inside a dark underground cavern. Blue gray stone columns, stalactites and misty layered cave depth, uneven rocky floor with sparse grass. Small silhouetted sword-wielding adventurer left of center with a long bright silver sword angled up to the right, little flowing red scarf. Threatening red glowing armored enemy at far right and subtle red ground lights. Top-left tiny game HUD with four red pixel hearts and one dark empty heart over a thin teal stamina bar. Moody charcoal navy and desaturated petrol blue, restrained crimson accents. Entire frame is the game itself, no text, title, border, watermark or outside UI. Crisp sophisticated pixel art.
